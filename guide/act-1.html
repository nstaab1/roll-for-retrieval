Why each numbered part is there. Point at one to see its lines.
(1) The client does the call. It refuses a file over 25 MB, which is gpt-transcribe's upload cap, before anything is sent. Under the cap it sends the file and writes one line to the cost log.
(2) The clip's length. Hosted transcription is priced by the minute of audio, so the length is what the price is worked out from. ffprobe reads it from the file.
(3) Dollars from the price table. The same table in src/config.ts prices every call in the cost log, never the provider's response, so an OpenRouter key and an OpenAI key log alike.
(4) Plain text, no timestamps. gpt-transcribe returns the words and nothing about when they were said, so nothing in it can be cited. It's for this comparison only.
(5) Written beside the clip. compare looks for <clip>.hosted.json next to the local transcript. The vector store reads transcripts/, so it never sees this file.

2 Run it

The tests send fifteen seconds of the clip to gpt-transcribe, twice, for well under a cent. Then run the call on the whole clip, which costs $0.045 at $0.0045 a minute. 

npm test -- 1
npm run transcribe:hosted -- audio/barovia-2025-12-29-windmill-finale.mp3

It prints the file it wrote, the wall time and the dollars. The file sits beside the clip as barovia-2025-12-29-windmill-finale.hosted.json.

3 Compare them

Once Whisper has finished in the first terminal, put the two side by side. 

npm run compare -- audio/barovia-2025-12-29-windmill-finale.mp3
  • Wall time. The hosted call takes seconds. Whisper took minutes on four cores.
  • Dollars. Local shows $0, with the codespace time beside it, because the machine you rent is what it costs. Hosted shows what the price table charges.
  • Text. Read the names. A name a model mishears is a name nobody can search for later.

5 Who said it?

None of these transcripts say who is speaking. Splitting a transcript by speaker is diarization. A hosted diarization model costs about $0.10 per audio hour, and it hands back Speaker 1 and Speaker 2, not names, so someone still listens to every night and names the speakers by hand.

We skipped it. The questions you ask the pipeline are about what happened at the table, and an answer cites the night and the moment, not the person. In the last hour you keep the DM's secrets out of player answers, and that doesn't need a speaker either: whatever the DM says at the table, the players heard. The secrets live in DM documents, and each document says who may see it.
