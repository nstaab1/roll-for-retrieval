Roll for Retrieval · The last hour

Does It Work, and What Does It Cost?

So far you've asked your pipeline one question at a time and judged each answer by eye. Now you ask it 10 questions, 3 times each, and get numbers back. Then you price a question from the cost log, swap one model for a pricier or newer one, and decide whether the upgrade is worth what it costs. No code.

Done when

  • your baseline and one swap printed side by side
  • an Evaluation line and a Cost line in DECISIONS.md

1 Run the eval

The eval set is eval-set.json. Each question names the night or document that answers it. 7 are one per night, 1 only the party document answers, and 2 have no answer anywhere, so they pass only by refusing. Every question is asked as katie, who sits at both tables and may see every answer. That way the score means the same before and after the access leak is fixed. 

npm run eval

It asks each question 3 times through the same ask you built, at your choices, gate included. Each line prints as its question finishes. 30 asks take about a minute and cost about $0.005.

2 Read the three numbers

  • Expected source in the top 5. The reranker's first 5 chunks include the night or document that answers. Search and the reranker don't sample, so this is one number, and the eval says so. A miss here is retrieval's fault: the answer model never saw the source.
  • Expected source cited. The answer's citations name that source. The eval reads the structured citations from Act 4, never the answer's text, so a lucky phrase can't count. It prints as a range, because the answer model samples its words.
  • Refused when it should. A question with no answer came back citing nothing. A range too.

Then read the question lines above the table. A question with its source in the top 5 that's never cited found the right chunk and lost it later: the prompt kept too few, or your refusal instruction turned it away. A question with no answer that cites a night got a confident answer to something that never happened.

On your own data, change the asker line in eval-set.json to one of your members, and write questions whose answers you know. Keep a couple that nothing answers.

3 Price a question 

npm run cost

The cost summary reads cost-log.jsonl, where every shipped client has written one line per call since Act 1. It adds them up by stage and model, and leaves out the calls npm test made. Hosted dollars come from the price table, never from the provider, so both kinds of key log alike.

Local stages log $0, so the last column prices their wall seconds at the codespace's $0.36 an hour. Local transcription and the reranker are cheap per call, but they're not free. The eval's table already priced one question the same way: hosted dollars, then local time.

4 Try one swap

Pick one swap. Each runs the eval again with one stage's model replaced, leaves src/choices.ts alone, and prints your latest baseline beside it.

  • A bigger embedding model. openai/text-embedding-3-large instead of openai/text-embedding-3-small. Its vectors don't match your index's, so the eval rebuilds the index at your chunk values first, for about $0.019. A second run reuses it.
  • A hosted reranker. cohere/rerank-v3.5 instead of the local Xenova/ms-marco-MiniLM-L-6-v2. It runs on OpenRouter only, and on an OpenAI key the eval says so. Its scores sit on their own scale, so your relevance threshold may gate differently.
  • A newer answer model. openai/gpt-5-mini instead of openai/gpt-4o-mini. It reasons before it answers, so its run is slower and writes more output tokens. 
npm run eval -- --swap large-embedding
npm run eval -- --swap hosted-reranker
npm run eval -- --swap newer-answer

Read the two columns. Did any of the three numbers move by more than the range already moves? What does a question cost now? Every run is kept in eval-runs/, which git leaves out, so you can run another swap later and still see your baseline. Tell the room which one you ran. A few results go on screen, so everyone sees all three.

5 Write it down

Open DECISIONS.md and write a line under Evaluation and a line under Cost. Say which swap you ran and whether you'd keep it, with the numbers that decided it. If the swap changed your mind about a stage, revise that stage's line too.

Swapped in ___. Cited went from ___ to ___ for ___ a question, so I'd ___.

One question costs ___ hosted and ___ s of local time.

These numbers come from rules you can read: a source in the top 5, a citation, an empty citation list. The next step is LLM-as-judge, where a second model grades each answer, but it isn't here today: a judge samples too, so you'd check one model's guess with another's.
